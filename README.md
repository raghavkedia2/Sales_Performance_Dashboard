Sales_Performance_Analysis_Dashboard
A comprehensive Microsoft Excel project that analyzes over 1,000 sales transactions to evaluate revenue, profit, regional performance, and product trends. The project includes data cleaning, advanced Excel formulas, PivotTables, PivotCharts, slicers, conditional formatting, and an interactive dashboard for business reporting.

Project Overview

This project demonstrates how Microsoft Excel can be used as a complete Business Intelligence (BI) tool for data cleaning, data transformation, business analysis, and dashboard development.

The project integrates multiple datasets (Orders, Customers, and Products) into a single master dataset using XLOOKUP, performs feature engineering, develops interactive PivotTables and PivotCharts, and presents key business metrics through an executive dashboard.

This project is designed to simulate a real-world sales analytics workflow performed by business analysts and data analysts.

Objectives
Clean and prepare raw business datasets.
Merge multiple datasets into one analysis-ready table.
Analyze sales and profitability across products, occasions, and cities.
Track business KPIs through an interactive dashboard.
Generate actionable business insights for decision-making.
Demonstrate advanced Microsoft Excel skills used in analytics roles.
Dataset Information

The project uses three related datasets.

1. Orders Dataset

Contains transactional sales information including:

Order ID
Customer ID
Product ID
Quantity
Order Date
Delivery Date
2. Customers Dataset

Contains customer information such as:

Customer ID
Customer Name
Gender
City
3. Products Dataset

Contains product information including:

Product Name
Category
Occasion
Price (INR)
Data Preparation

The following data cleaning and validation steps were performed before analysis:

Converted raw data into Excel Tables
Checked duplicate records
Verified missing values
Standardized text formatting
Validated date fields
Verified relationships between datasets
Merged datasets using XLOOKUP
Created a master analysis table
